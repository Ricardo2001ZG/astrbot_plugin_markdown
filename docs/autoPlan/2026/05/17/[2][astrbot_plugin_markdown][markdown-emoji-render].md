### Step 2: 创建 Emoji 处理模块
```python
# src/emoji_handler.py

import emoji

class EmojiHandler:
    def process_emoji(self, text: str) -> str:
        """将 Emoji 短代码转换为 Emoji 字符"""
        return emoji.emojize(text, language='alias')
    
    def demojize(self, text: str) -> str:
        """将 Emoji 字符转换为短代码（反向）"""
        return emoji.demojize(text)
```

### Step 3: 定义支持的 Emoji 短代码格式
